NVDA Clipboard Append Add-on

This add-on allows you to collect multiple pieces of text on the clipboard without replacing the previous content. This add-on works in a similar way to the FSClipboard feature available in the JAWS screen reader.
Normally, when you copy text, the clipboard is overwritten by the new text. With this add-on, you can keep adding selected text to the clipboard and paste everything later at once.

When you select text and press NVDA+Windows+C, the selected text is appended to the clipboard instead of replacing the existing content. Each new selection is added on a new line. You can repeat this command while reading a document, webpage, or any other text to collect several pieces of text.

Later, when you press paste (Control+V), all the text you collected with NVDA+Windows+C will be pasted together in the order in which they were copied.


Keyboard commands

NVDA+Windows+C – Append the selected text to the clipboard.
NVDA+Shift+Delete – Clear the clipboard. NVDA will announce “Clipboard cleared”.

You can change these keyboard shortcuts from NVDA’s Input Gestures dialog if youprefer different commands.
